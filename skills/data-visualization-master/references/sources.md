# Sources

Citations behind the rule keys in `SKILL.md` and the column keys in
`references/points-of-view.md`. Read when a "why" is asked, when a research
run verifies or extends an entry, or when a critique must justify a call.

Provenance marks, following `evident-charts` conventions: (2nd) confirmed only
through a secondary source; (preprint) not peer reviewed; (book) paraphrased,
not re-checked; [UNVERIFIED] could not be verified. Unmarked entries were
verified directly.

All *Points of View* DOIs below were resolved against the Crossref metadata
record (journal, volume, page, authors) on 2026-09-26.

## Chart-level bibliography

The sibling skill `evident-charts` maintains the complete per-rule chart-level
bibliography (channels, chart types, axes, text, color, integrity,
uncertainty, accessibility, LLM visualization tendencies) in
`skills/evident-charts/references/sources.md`. This file covers the corpus-
level and principle-level sources; do not duplicate the evident-charts
entries — extend them there is NOT allowed (upstream-owned); instead add new
findings here and let the master skill cite them.

## Maintenance (for research runs)

When adding an entry:

1. Verify the bibliographic record against Crossref
   (`https://api.crossref.org/works?query.bibliographic=...`) or the
   publisher page before writing it here. Record the DOI, not a bare URL.
2. Format: `- [KEY] Authors year, Title, Venue vol(issue). https://doi.org/...`
   followed by any provenance mark: `(2nd)`, `(preprint)`, `[UNVERIFIED]`.
3. Keys are stable: once used in a rule, a key's meaning does not change.
   Corrections append a `Corrected:` note rather than silently rewriting.
4. New rule lines in `SKILL.md` must reference only keys defined here or in
   the evident-charts bibliography.
